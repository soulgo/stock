# 交易知识库 · 索引

> 用途：把「看懂的图 / 想明白的规律 / 验证过的方法」沉淀成可检索、可执行的条目，后面问相关问题时直接调用，不用重新解释。
> 建立：2026-11-05　｜　维护：每条知识都要有「口径 / 结论 / 边界」三件套，缺一条不收。

## 知识生命周期（最小约定）

每条 K 文档顶部维护以下字段；版本记录内容变化，不代表用户已采纳或规则已生效。参考材料经用户认可，也不自动获得交易执行权。

| 字段 | 记录要求 |
|---|---|
| 来源 | 原文链接或文件位置、作者/机构、日期/页码；无法取得时明确标“待补”，区分原作者结论与本系统推导 |
| 状态 | **正式规则**（用户明确确认的范围/规则）；**观察证据**（可跟踪，尚非独立验证）；**样本内探索**（小样本或事后拟合，不能外推）；**暂停/撤销**（说明原因及替代项） |
| 版本 | 从 `v1` 起递增；记录修改日期和变更摘要。只改错字可不升版；不覆盖旧版结论的历史依据 |
| 采纳 | 记录“待用户确认 / 已确认”及确认日期；代码接入、报告展示与规则采纳分开记 |
| 复核 | 写明下一复核条件/时间、必要样本和不足；未满足时维持原状态，不暗示已验证 |
| 撤销 | 写明失效/撤销条件；触发后标为暂停或撤销，保留旧版并从有效规则引用中移除 |

状态仅说明当前证据和采纳情况，不改变指标阈值、范围或仓位规则。相互冲突时保留两种原文与影响，待用户裁定后再更新规则。

## 指标前瞻验证

评估前冻结指标版本、阈值、适用范围与对照基准，记录每条数据的实际发布时间和信号生成时间，禁止使用当时尚不可得的数据。分别保留样本内探索与之后独立样本外结果，记录样本数量、缺失与未成熟样本；样本不足只报告不足，不宣称有效。共同来源或相互派生的指标不算独立证据。`fwd20` 当前仅对 K04 以之后第 20 个有效观测日的点位计算，缺日会延长周期，不等同严格 20 个交易日；K05 月频点位不混入。

> **范围硬约束（K00）**：只做**宽基 ETF**，核心是跟**国家队在宽基的进出**。
> 行业、主题、策略（红利/低波/价值/成长）、跨境（标普/纳指/恒生）一律不在范围内 —— 再好的形态也不做。

## 怎么用这个库

1. 先看下面的**检索表**，按触发词定位条目。
2. 每条知识末尾都有**「什么时候失效」**。引用结论前先读这一节，很多误用都发生在这一节。
3. 数字一律标 `≈` 或用「读图值」，不把图上估读的数字当精确值用。

## 与项目现有资产的关系

| 资产 | 干什么 | 和本库的关系 |
|---|---|---|
| `docs/KDAS手册.md` | KDAS 关键点体系手册（个股/分时/资金验证） | **微观**：单只标的的成本线与买卖点 |
| `strategy_rules.md` | 做 T 的四象限、资金结构细读、午盘格式 | **日内**：当天怎么动手 |
| `tools/broad.py` | 16 个指数族的宽基全景（规模/分位/距年线/活跃度） | **选池**：K00 的落地工具，回答「做哪个宽基」 |
| `etf_flow.py` | 国家队 24 只载具（主池 20 + 观察 4）的份额每日快照，输出加仓指数 | **资金**：K01 的落地工具，回答「国家队在不在」 |
| `indicators/equity_bond_ratio.py` | 股债比价每日读数 + 触线点位换算 → `data/equity_bond_ratio.csv`、手机端看板 | **区域**：K04 的落地工具，已内置进 `brief.py` 与报告「股债比价」卡 |
| `tools/sweep.py` | 全市场 ETF 大级别支撑/压力扫描 | **中观**：买在哪（K02 的落地工具） |
| `tools/grid_plan.py` | 4 年日线网格参数测算 | **执行**：区间内怎么摊 |
| `indicators/credit_impulse.py` | 信贷脉冲（含/剔除政府债）月度读数 + 与沪深300同比的互相关领先期 | **宏观**：K05 的落地工具，否决权口径待裁定；已内置日报和报告卡 |

层级关系：**K05 定信用周期（否决权）→ K00 定范围 → K01/K03 定环境 → K02 定位置 → K04 定区域估值 → broad/sweep/网格 定动作 → 做 T 规则 定执行**。

> K05 在最外层且有**否决权**：脉冲深度为负时，即使 K04 触线也只能小额左侧；脉冲转正时，即使 K04 在观察区也可按 K03 正常做。它管的是「这一整轮还能不能加仓」，不是「今天买不买」。

> K04 和 K03 的分工容易混：**K04 说「便宜」（空间），K03 说「能不能动手」（状态）**。④减 期间即使 K04 触线，也只能小额左侧，必须等 K01 份额抬升确认。

> 两套宽基口径的差别：`tools/broad.py` 每族选一只载具；`etf_flow.py` 使用主池 20 只及观察池 4 只。份额变化不等同于国家队实际持仓变化。
