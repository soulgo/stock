## 一、口径（三件套之一）

| 项 | 值 |
|---|---|
| 分子（腿A） | **沪深300全收益指数 H00300.CSI**，基日 2004-12-31 = 1000，含分红再投 |
| 分母（腿B） | **万得混合债券型二级基金指数 885007.WI**，基日 2003-12-31 = 1000，净值型（分红再投） |
| 比价 | A ÷ B |
| 频率 | **周频看形态，日频算数值**（博主原图是周线） |
| 阈值 | **1.0**（图上红色虚线，跌破即进入浅红区） |
| 当前 | 2026-11-13 = **1.181**（博主）→ 2026-11-16 = **1.173**（本脚本复算） |

两个"全收益"很关键：分子分母都含分红再投，才可比。换成沪深300**价格**指数去比，长期会系统性地把比价算低（沪深300 股息率约 2.5%/年），线会假性地提前触到。

## 二、为什么这条线有意义（原理，别只记数字）

**两线重合 = 长期持有沪深300 的收益，已经退化到和二级债基一样。**

可你承担的是股票的波动，却拿不到任何额外补偿 —— 股票相对债券的长期超额收益被清零。这种状态在逻辑上只能是极端低估。本质上它是"股债性价比（ERP）"的**累计收益版**，不用设窗口、不用算 σ，把两条线叠一张图就能看。

**为什么锚是二级债基、不是纯债：**
二级债基的收益率更接近险资、理财、年金这些**配置资金真实的机会成本** —— 纯债 3% 盖不住它们的负债成本，必须"+"点什么。用纯债指数做锚，20 多年一次都没触发过，是失败选手。所以"锚的选择"本身就是这个指标最脆的一环，换锚 = 换结论。

## 四、换算链（这条最重要，可以直接迁移）

博主没写、但你必须会算的一步 —— **怎么把比价翻译成点位**：

```
k = 全收益 ÷ 价格 = 6048.32 ÷ 4016.29 = 1.50595      ← 分红累积系数，每年漂 +2.5% 左右
比价线对应点位 P* = 比价 × 债腿 ÷ k
```

反推一遍：债腿 5121.91 就是"比价 = 1.0 时的全收益点位"，再 ÷ k 换成价格指数点位，得 3401。

**k 会慢慢变大**（分红再投），所以同一个比价，明年的点位会比今年高一点。这个系数每次重锚时要重算，不要写死。

**触线点位不是静止的**：线的上移速度 ≈ 债腿年化 − 沪深300 股息率。
- 历史段：债腿 2004 以来年化 **7.1%**，减股息 2.5% → 线每年抬 **4% 上下**；
- 前瞻段：10Y 国债已到 **1.71%**（中证债券估值日报），二级债基前瞻 2.5%~3.5%，减股息后**线基本走平（0~1%/年）**；
- 实操：**一年内把 3390~3400 当固定区域用没问题，每年 12 月重算一次。**

> 别用触线点反推线的斜率。触线点是"比价的局部极值"，不等于 1.0 线本身（2024 年最低只到 1.017、没真跌破），反推会差出好几年。

## 六、怎么用它管仓位（用户要的"管理与关注"）

### 6.1 观察节奏

**周频就够。** 这是周线指标，日线噪声不改变结论。建议：
- 每周五收盘后跑一次 `python equity_bond_ratio.py`，看比价档位有没有变；
- 只有跨档（比如 1.10 → 1.05）才需要动脑，其余时间不动；
- 不要因为日内跌 1% 就去看，那是在用日线噪声干扰月线决策。

### 6.2 分档动作

| 比价 | 档位 | 动作 |
|---|---|---|
| ≥ 1.50 | 贵·减股 | 股票贵过债，股票腿降到最低，新钱进债/货币 |
| 1.30 ~ 1.50 | 偏贵 | 开始减，宽基不再新增 |
| 1.15 ~ 1.30 | 观察区·远 | 不看这条线。按 K03「④减」执行，宽基只减不加 |
| 1.05 ~ 1.10 | 预备区 | 做T弹药归位，宽基不做左侧大额 |
| 1.00 ~ 1.05 | 第一档 | 第一笔 ≤ 计划额 1/3，等二次确认 |
| 跌破 1.00 | 触线区 | 分批推进，每批间隔 ≥10 个交易日或再跌 3% |
| 跌破 0.95 | 惯性区 | 历史级区域，剩余弹药留这里 |
| ≤ 0.90 | 极限区 | 历史最深 0.78，此时该想的是敢不敢，不是买不买 |

### 6.3 和现有体系的串联（不能单指标梭哈）

```
K04 定「区域」→ K01 定「钱来没来」→ K03 定「现在能不能动手」→ 做T规则定「怎么下」
```

- **K04 触线只说明"便宜"，不说明"见底"**。必须配 K01（国家队 ETF 份额是否同步抬升）做资金验证；
- 触线期间若 K03 仍是「④减」，那就是"便宜但在下跌"，只能小额左侧、不能转攻；
- 触线是**宽基专属**逻辑：沪深300 全收益指数对应的就是宽基，行业/主题 ETF 不适用（它们的"债券替代"逻辑不存在）。

### 6.5 上沿：同一条线的另一半（什么时候该往债挪）

比价是一根**双向**的轴，不是只会告诉你"股票便宜"：

| 端 | 含义 | 对应动作 |
|---|---|---|
| ≤ 1.00 | 股票的超额收益被跌没了 | 买股票（分批） |
| ≥ 1.50 | 股票相对债贵了，拿股票的风险补偿被透支 | 减股票、新钱往债挪 |

**当前上沿读数（2026-11-16）**：1.30 线 = **4,410**（+10.8%）、1.50 线 = **5,088**（+27.9%）。

**历史峰值**（原图读值）：2007 ≈ **2.4**（图上最高）、2009 ≈ 1.6、2015 ≈ 1.5、2021 ≈ 1.55。
2026 这轮没走完，但 52 周高 5,064 折算比价已基本踩到 1.5 —— 和前三轮同一个水平。

**一个必须记住的不对称：**

- **底可以定量**，因为分母（债腿）是条稳定复利的"地板"，地板会自己往上长，所以 1.0 线是硬的、算得出点位；
- **顶不能定量**，因为泡沫没有上限 —— 2007 一口气冲到 2.4。1.5 是"过去 16 年反复认的水平"，是经验带，不是数学边界。
- 所以用法不同：**下沿当扳机，上沿当温度计**。到 1.5 不等于立刻清仓，等于"该开始减、并且不能再加"。

**股债走廊**：下沿 3,392（触线）→ 上沿 5,088（偏贵），当前 3,980 落在 **35%** 位置。

### 6.6 债端：这条线答不了的部分

它只回答"股**相对**债贵不贵"，**不回答"债本身贵不贵"**。后者得看绝对收益率，是另一个指标：

| 读数（2026-11-16） | 值 | 含义 |
|---|---|---|
| 10Y 国债收益率 | 约 **1.71%**（2026-07 中证债券估值日报） | 20 年低位区 |
| 511260 十年国债ETF | 52 周分位 **88%**，近一年 +3.15% | 在一年高位（=收益率低位） |
| 511010 国债ETF | 52 周分位 **93%**，近一年 +2.34% | 同上 |
| 511090 30年国债ETF | 52 周分位 **77%**，近一年 +1.08% | 同上但久期更长 |

**结论：现在不是"债比股好"，而是"两个都不便宜"。** 股没跌到触线，债在一年高位、票息只有 1.7% 上下 —— 所以这个指标现在两端都不给信号，现金留在货币 ETF（银华日利）是合理位置，不必为了"避险"去买拉不开差距、却多扛久期风险的债。

**什么时候"买债"才成立**，两条路要分清：
1. **相对切换**（股贵→挪债）：等比价到 1.30~1.50，对应沪深300 4,410~5,088。这是这个指标能给的部分。
2. **绝对配债**（降波动/现金管理）：跟这个指标无关，看 10Y 收益率能给你多少票息、够不够覆盖你的负债成本。10Y 在 3% 以上才谈得上"配债划算"，1.7% 不构成理由。

### 6.7 当前位置（2026-11-16）

- 比价 1.173，还在「观察区·远」，**离触线 14.8%、离偏贵 27.9%**，走廊 35% 位置，两端都不构成动作；
- 但沪深300 近 60 日已跌 14.7%，和"距触线 14.8%"几乎相等 —— 若这个速度线性延续，一季度内就能摸到 3390。**这是情景，不是预测**，速度绝不可外推；
- 手上 563800（A500，不是沪深300）已在 52 周低点 1.019。若沪深300 跌到 1.00 线，563800 按同比例约 0.874，A500 中盘权重更高、弱市通常跌更多，实际可能更低 2%~4%。

## 七、边界与失效条件（引用结论前先读这节）

1. **样本极小**：8 次触线、图上只标 4 次。87.5% 胜率建立在个位数样本上。
2. **隐含假设经济不长期停滞**。若出现长期低增长，均值回归可以迟到很久，线也不会自己抬上来。
3. **债腿自己会动**。2024–2026 的债牛把线抬高了，等于"底"在往上走；反过来若利率快速上行，线会加速上移，同样的指数点位比价会更低（更容易触线），但那时是"股债双杀"，不是机会。
4. **1.0 不是精确底**。四次里三次跌破，最深到 0.78。**它是区域信号，不是时点信号**。
5. **锚敏感**。把锚换成纯债指数，22 年零触发 —— 结论完全反转。所以这个指标的价值有一半系在"二级债基"这个锚上。
6. **数据可得性**：885007 是 Wind 专有指数，**没有公开接口**。必须"锚点 + 代理推进"，见第八节。
7. **β 假设**：二级债基约一成股票仓位，用 β=0.12 代理。若遇转债流动性危机（2022 年那种），实际回撤会大于这个假设。
8. **不适用于新宽基**：若后续主仓转成中证A500、创业板，要换对应的**全收益**指数重算，不能直接套沪深的线。

## 八、工具与数据（怎么每天/每周复现）

### 8.1 数据怎么来

| 腿 | 来源 | 可靠性 |
|---|---|---|
| 腿A 沪深300全收益 H00300 | 中证官网 API `csindex-home/perf/index-perf` | **精确**，实测 11-13 = 6048.32 与博主一致 |
| 腿A' 沪深300 价格 000300 | 同上 + 腾讯 qt.gtimg.cn 实时校验 | 精确（3979.80 与博主一致） |
| 腿B 885007 | **无公开接口** | 锚点 + 代理推进 |

⚠ **中证官网会返回坏窗口**：实测 2026-11-01/02 返回同一个值、11-13 有时返回 11-16 的值（滞后一天）。所以脚本做了三件事：多次取数留候选值 → 用 k 系数（全收益÷价格 = 1.5060±0.3%）配对 → 对不上的日期直接丢弃。**单次取数不可信，这条要记住。**

### 8.2 债腿的代理模型

```
B(t) = B_anchor × (1 + r_中证全债) × (1 + β × r_沪深300)
B_anchor = 5121.91 @ 2026-11-13，β = 0.12
```

锚点日的绝对值来自博主公布值（= Wind 口径），之后用中证全债 H11001 推进。误差主要来自"中证全债 vs 885007 的利差"（885007 年化比纯债高约 2.5~3pp），**对"距触线还有多少 %"的影响在 ±1% 量级**，对绝对值的判断够用。

**拿到博主/万得的新数字就重新锚定**，不用改代码：

```bash
python equity_bond_ratio.py --date 2026-12-05 --bond 5098.4      # 给了债腿值
python equity_bond_ratio.py --date 2026-12-05 --ratio 1.152      # 只给了比价，自动反推
```

### 8.3 日常命令

> **已内置到日报**：`brief.py` 的「九、股债比价」（早盘）/「十一、股债比价」（午盘）会自动带上本指标，
> `report_gen.py` 渲染成「股债比价」卡片（走廊进度条 + 两端点位 + 债端温度 + 对持仓的等比价），
> 排在「持仓」之后、「资金面解读」之前。**日常不需要单独跑下面这条命令**，只在盘后复盘或重锚定时用。

```bash

```

看板里已经含：比价大字 + 双向档位尺 + **股债走廊**（3,392~5,088，标出当前位置）+ 双向档位表 +
**债端温度**（511260/511010/511090 的 52 周分位）+ 换算到 510300/510310/159919 的两端线价 + 563800 推算。
