## 0. 先看这一页（速查卡）

**一句话**：KDAS 不是均线，是「从某个关键时点开始，市场所有成交的加权平均成本」。价格突破某条线 = 这批筹码整体解套/获利，行为会变。

**六状态 → 六动作 → 六档仓位**

| 状态 | 判定（一句话） | 动作 | 仓位 |
|---|---|---|---|
| 自然寻底 | K 线一路向下，站不上强弱分界线 | 观察，不买，不接飞刀 | 0–1 成 |
| 右侧买点 | 从底部**突破**强弱分界线那一刻 | 建仓信号 | 2–3 成 |
| 震荡区间 | 压力位与支撑位之间来回 | 底仓 + 高抛低吸做 T | 3–5 成 |
| 右侧空间 | 突破后，中远期压力位还很远的真空段 | 可加仓，可开新的向上接力 | 5–7 成 |
| 右侧趋势 | 上方已无明显压力位 | 持有，只盯移动支撑，破位即减 | 持有不加 |
| 右侧追涨 | 涨了一大截才想上车 | 不参与 | 0 成 |

**唯一状态开关**：能不能站上「强弱分界线」（接力出来的最后一两条线）。
站不上 → 左半场（寻底 / 等右侧买点）；站上了 → 右侧世界。

**三条铁律**
1. 破最近一条 KDAS 支撑 → 逐级降档减仓，不等反弹确认。
2. 第一次接触压力/支撑，强度最高；反复回踩，强度衰减。
3. 只有「关键点附近」的资金数据才有意义，其他时间的资金流是伪装。

## 1. KDAS 到底是什么

原文定义（《KDAS 是一种交易思维方式》，2025-06-17）：

> 很多人看了 KDAS 的线，总觉得它是个单纯的均线系统。其实 KDAS 的全称是 **Key point Data Analysis System**（关键点的数据分析体系）。
> KDAS 是能够**兼容你所用到的其他技术指标和数据分析的**。

三个要点：

1. **它是坐标，不是信号**。KDAS 只负责把价格切成一个个「关键点」，告诉你「现在该买、该卖、还是该等」。
2. **它是容器**。资金流（Level2 主动买卖）、成交量、散户活跃度、融资盘……都要**挂在关键点上**才有解释力。不做关键点分割的资金数据，价值极低。
3. **它的有效性来自行为金融**：关键点处最考验持仓者的人性，主力在那个位置无法继续伪装（拆单、对倒），会露出真实动作。

作者原话很直白：

> 在大部分、非紧急的时间里，资金都可以通过拆单、对倒的方式**伪装自己、掩盖行踪**；**只有在夜深人静孤男寡女的关键节点，才会原形毕露。**

**为什么「关键点」有效——巴甫洛夫的那只狗**（《巴甫洛夫的股》，2025-06-14）

一轮行情的顶部不是画出来的，是「训练」出来的：

- 反复在喂食前摇铃 → 狗听到铃声就流口水；
- 反复奖励「冲高买入的人」和「回调买入的人」→ 让他们赚钱、让他们爽、让他们去嘲讽空头；
- 空头闭嘴后，产生**稀缺性与被剥夺的超级反应倾向**（FOMO）→ 所有水手一拥而上接盘 → 收网。

盘面语言：**9 次以上的间歇性强化建立激励机制 → 造出「吃酸菜的长官」引发社会认同 → 再冲高扇空头耳光 → 空头闭嘴后收网。**

对应到中证全指的图上（2025 年那波）：指数一路上台阶，每次冲高和回调都给买入者奖励（图上连续黄箭头），最后一根大阴线「收网」，三天散户割肉 4000 亿。

**这条认知的用处**：当你发现自己因为「上次这么买赚了」而条件反射下单时，先问一句——现在是喂食阶段，还是收网阶段？「铃声多久结束的选择权，在巴甫洛夫手里。」

## 2. 指标原理：五条线是「关键时点之后的平均成本」

这是整套体系的技术底座，也是原文没展开、但**源码写得很清楚**的部分。

### 2.1 核心公式

个股版（`KDAS个股1~4`）的每一组线，做的都是同一件事：

```
锚点日期 → BARSLAST 求出「距锚点多少根 K 线」
均价     → AMOUNT / (VOL*100)          // 成交额 ÷ 成交股数 = 当日成交均价
成本线   → SUM(均价 × VOL, N) / SUM(VOL, N)   // 从锚点起的成交量加权平均价
```

也就是：**从锚点日到今天的 VWAP（成交量加权平均价）**。源码里 X_4~X_7、X_8~X_11……五组结构完全一样，只是锚点日期不同。

分时版则用典型价加权：

```
典型价 = (HIGH + LOW + CLOSE) / 3
成本线 = SUM(典型价 × VOL, N) / SUM(VOL, N)
```

### 2.2 三个必须理解的推论

**① 颜色 ≠ 强弱。**
源码里颜色是写死的：橙（`COLOR007FFF`）→ 红 → 黄 → 绿 → 灰（`COLORLIGRAY`），对应参数 1~5 组。
**颜色只代表「第几个锚点」，不代表支撑强度。** 原文明确说：「排序大家可以自行决定，没有统一的标准说某个颜色对应不同强度。」
实操中之所以常见「橙线在最低、灰线在最高」，是因为通常按时间顺序设置锚点：锚点越早、跨越的行情越长，VWAP 被摊得越低（上涨段）。

**② 线会随价格移动，不是水平直线。**
因为它是「截至今天的累计均价」，价格一走，线就跟着走。这也是为什么它能当**移动止损线**用——上涨趋势里，支撑位会自己往上抬（文章里反复出现「支撑位提高到 1.26 / 1.622 / 1.04」就是这个意思）。

**③ 一条线 = 一批筹码的生死线。**
价格在某条线之上，意味着「从那个时点买入的人整体是赚的」，抛压小、承接强；跌破，则这批人整体套牢，反弹到线附近就是解套盘涌出的位置。所以「突破 = 解套 + 新增买盘」，「跌破 = 套牢 + 止损盘」。

### 2.3 关于有效期校验（技术说明）

源码开头有一段所有版本都一样的代码：

```
X_1 := 1260430;              // 2026-04-30
X_2 := HHV(DATE, 0);         // 历史最后一根 K 线的日期
X_3 := IF(X_2 > X_1, 1, 0);  // 数据超过该日期 → 置 1
```

当 `X_3 = 1` 时，所有画线语句都返回 `DRAWNULL`，图上只剩 `DRAWTEXT_FIX` 的水印文字。
**这是原作者内置的版本有效期控制**，不是你装错了。若发现「只有文字没有线」，先检查数据日期是否已超过 2026-04-30；新版本请回原作者处获取。

## 3. 四套指标的定位与适用范围

| 指标 | 画线位置 | 锚点 | 适用品种 | 主要用途 |
|---|---|---|---|---|
| **KDAS 个股 1~4** | 日线主图叠加 | 5 组「年-月-日」 | A 股个股、ETF（**不适用指数**） | 日线级别的关键点、接力、状态判定 |
| **KDAS 分时** | 分时图主图 | 3 组「日 + 时 + 分」 | 指数、港美股 | 日内关键点，隔日短线做 T |
| **KDAS 自动分时 3** | 分时图主图 | 自动：近 N 日最高/最低价之后的 VWAP | 指数、港美股 | 不用手填日期，自动跟随最近的高低点 |
| **KDAS 副图指标 2** | 副图 | 无 | 通用 | RSI9 + 30 日极值 + OBV 的超跌/超买提示 |

**版本注意**：`个股1~4` 的用法注释写的是「V2 版更新了计算公式，仅用于个股和 ETF，不适用于指数」。四个文件源码完全相同，**区别只在默认锚点日期**，属于同一指标的不同预设。

**为什么个股版不能用于指数**：指数的 `AMOUNT` / `VOL` 口径与个股不同（指数成交量是成分股累加、无成交额概念），算出来的「均价」没有成本含义。

## 4. 六种状态：整套体系最该背下来的东西

原文（《蒸馏出一份操作手册》，2026-09-23）：

> 然后把任何一只 ETF，归进六种状态之一。**这是整套体系最值得背下来的东西**，因为日更笔记每天都在用这六个词给板块贴标签。

### 4.1 状态机

```
        ┌──────────── 跌破最近一条 KDAS 支撑：逐级降档 ────────────┐
        │                                                          │
        ▼                                                          │
  ┌─────────┐  突破强弱分界线  ┌──────────┐  上方压力位还远  ┌──────────┐
  │ 自然寻底 │ ──────────────▶ │ 右侧买点 │ ──────────────▶ │ 震荡区间 │
  └─────────┘                  └──────────┘                 └────┬─────┘
    观察·不买 0-1成            建仓信号 2-3成             3-5成底仓做T
                                                                 │
                                          突破压力位后的真空段   │
                                                                 ▼
  ┌──────────┐   离买点已远   ┌──────────┐  上方压力位清空  ┌──────────┐
  │ 右侧追涨 │ ◀────────────  │ 右侧趋势 │ ◀────────────── │ 右侧空间 │
  └──────────┘   0成·不参与   └──────────┘                └──────────┘
                               持有不加·破支撑即减         5-7成·可加仓
```

### 4.2 状态判定表

| 状态 | 判定 | 对应动作（原文口径） |
|---|---|---|
| **自然寻底** | K 线一路向下，站不上强弱分界线，只能用向下接力模式不断划线 | **不买，等。**「等待企稳弱转强后进入震荡区间的右侧机会」 |
| **右侧买点** | 从底部**突破**强弱分界线，宣告自然寻底结束 | **建仓信号。** 此前向下接力的各条线全部转为压力位，需逐级突破 |
| **震荡区间** | 在压力位与支撑位之间来回 | **底仓 + 高抛低吸做 T。**「震荡区间一定要积累些做 T 的利润，这样哪怕后面跌破趋势，撤离也不会觉得亏得慌」 |
| **右侧空间** | 突破后，中远期压力位还很远的真空段 | **可加仓**，可开启新的向上接力；但「不能自己脑补以为这是随时都能买入的右侧买点」 |
| **右侧趋势** | 上方再无明细压力位 | **持有**，只盯「接力模式下不断提高的支撑位」，破位即减 |
| **右侧追涨** | 突破进入右侧趋势后再介入 | **不追。** 已偏离买点，盈亏比差 |

### 4.3 三个「右侧」千万别搞混（新手最大翻车点）

> 突破那一刻买，是**右侧买点**；突破后上方还有空间，是**右侧空间**；等涨了一大截才想上车，那叫**右侧追涨**。

还有一种最亏的：

> 两三根大阳线直冲中远期压力位附近，这时候反而**不是买点，是卖点**（特别是存量资金时期）。

原因是：右侧空间很小时，两三大阳线就把空间走完了，你看到「右侧空间」四个字就冲进去，实际是在压力位下方接盘。**先认状态，再定动作。**

## 5. 接力模式、拆线、强弱分界线

### 5.1 接力模式

> 当股价突破（跌破）前一条 KDAS 线之后，引出下一条 KDAS 线，不断突破（跌破）就不断引出新的线——跟接力赛一样，就成为**接力模式**。

- **向上接力**：突破一条 → 把锚点上移到这次突破日 → 画出下一条 → 再突破 → 再画。趋势行情里，每一次突破都是持股的确认，**不断抬高的支撑位就是移动止损线**。
- **向下接力**：跌破一条 → 锚点下移 → 画出下一条更低的线。用来在下跌中一级一级找可能的止跌位。

图示案例（黄金股 ETF 永赢 517520，向上接力）：价格从 1.14 一线起步，依次吃掉橙线 → 绿线 → 黄线 → 红线 → 灰线，每一根黄箭头都是一次「接力突破」，最后冲上 3.391。同一张图里，破位后又转成向下接力，跌破的线依次变成压力。

### 5.2 拆线

> 遇到灰线后突然加速大涨，接力模式下 5 根线就不够用了，这时候可以**拆掉前面的橙线、黄线、绿线**，继续在灰线后面接力。

意思是：**参数是有限的（5 组），但行情可以无限接力**。当价格已经远离早期锚点，早期那几条线对当下毫无指导意义，就把它们的锚点改到最新的关键日，让「有效的五根线」始终贴着当前价格。

COMEX 黄金那张图就是这个过程的完整样本：右侧趋势 → 震荡区间 → 向下接力，五条线在顶部密集（拆线后重新接力），随后逐级被跌破。

### 5.3 强弱分界线

> 在（向上、向下）接力模式下，接力出来的**最后一两条线**就是强弱分界线。

- **全体系唯一的状态开关**。
- 向上接力模式：**跌破**强弱分界线 → 离场信号。
- 向下接力模式：**突破**强弱分界线 → 进场信号（右侧买点）。

### 5.4 自然寻底

> 如果 K 线走势一直向下，一直站不上强弱分界线，就是自然寻底的过程，只能一直用向下接力模式划线接力。

酒 ETF 鹏华（512690）的样本：一路向下接力了**六根**才寻底结束（第 6 根是作者手动补的，为了一张图展示后面的压力位）。

- 自然寻底的终点 = **站稳最后一根 KDAS**，此时发出右侧买点。
- 寻底结束后进入震荡区间，之前向下接力的绿、黄、红、灰、橙**全部变成压力位**，「需要一点一点突破，越靠上的压力越强」。
- 全部突破 → 进入右侧空间/右侧趋势。

### 5.5 右侧空间与右侧趋势的区别

以科创新能源 ETF 鹏华（588830）为例：

- 橙线、绿线 = 中远期压力位；跌破它们之后开始向下接力。
- 刚突破黄线、红线 = **右侧买点**。
- 站稳灰线后，灰线与绿线、橙线之间的大空间 = **右侧空间**，可开启新的向上接力。
- 逐步突破橙线、绿线，且上方再无压力 = **右侧趋势**。

特殊情况：右侧空间很小时，两三根大阳线直接摸到中远期压力位 → 此时是卖点不是买点。

## 6. 压力位 / 支撑位的实战规则

原文比喻：

> 通俗理解压力位、支撑位就像作战地图上的堡垒、战壕、城门楼。到了压力位就容易冒出抛压，到了支撑位就容易遇到友军——但能不能攻破还要看到了那个节点后，多空双方力量的对比。

三条经验：

1. **第一次接触时，抛压/支撑最强。** 港股通医药 ETF 鹏华（513700）为例：第一次摸到橙线 0.62 附近，直接一根大阴线被打回，之后再上来才逐步消化。
2. **最不折磨人的走势是「接触即秒突破」**，不拖泥带水；反复磨、反复回踩的，往往突破质量差。
3. **强度会衰减。** 反复回踩同一支撑，说明买盘在被消耗；反复冲击同一压力，说明抛压在减少——但方向取决于量能和资金，不取决于次数。

**日内强弱分界线**是另一个层次：文章里常出现「日内强弱分界线 0.733，不破不用止盈」「0.595 可以做 T 参考」，指的是**当日多空分界**，用于做 T 的止盈止损，不是日线状态开关。

## 7. 组合拳一：KDAS + Level2 资金流（关键点验证）

这是 KDAS 最核心的用法：**用资金流验证关键点的攻防**。

### 7.1 案例：明月镜片（301101），2025-06-17

**盘前已定的关键点**（来自前期 KDAS）：
- 上方压力：灰线 **49.3**
- 下方支撑：红线 **46.03**、橙线 **43.3**

**观察窗口**：股价临近 49.3 的前后，即 **10:03 之前**。

**10:03 的 Level2 数据**（图中标注）：

| 项目 | 数值 |
|---|---|
| 价格 | 49.17（涨幅 6.80%），均价 47.48 |
| 主力总买入 | +284.0 万 |
| 主力总卖出 | **−607.0 万** |
| 主力主动买入 | +147.0 万 |
| 主力主动卖出 | **−486.0 万** |
| 被动（挂单）卖出 | −121.0 万（原文写「−121 亿」，应为笔误，607−486=121 万） |
| 累积主动成交占比 | 19.66% |
| 累积被动成交占比 | 9% |

**读法**：
- 10:03 之前有多根大红柱 = 主力主动买入拉升，这是「抬轿子」阶段。
- 到 49.3 附近，**长绿柱（主动卖出）+ 被动卖出同时出现** = 不再伪装，开始真出货。
- 这坨大筹码卖出后，后续**再没出现过大额主力主动买单**，只剩小额卖单和主动卖单 → 属于「大单跑完，改用小单/伪装散户单出货」。

**结论**：关键点附近出现「不再伪装的大单卖出」= 跟着跑路的信号。

### 7.2 洗盘 vs 出货：一条判别式

| 现象 | 判断 |
|---|---|
| 资金暂停主动买，反手用**小单主动卖**制造恐慌 | 可能是**洗盘** |
| 资金暂停主动买，反手用**大单主动卖** | 大概率**真出货**（尤其 100 亿市值以下的小公司） |

原文提醒：小单出货在资金流图上是**看不见的**（会被拆成散户单），所以「看不见大单」不等于「没在出货」，要结合「大单跑完之后有没有再出现大额主动买」来判断。

### 7.3 使用纪律

- **只在关键点附近看资金数据**。非关键点的时间，数据可以被拆单、对倒随意伪造，看了只会误判。
- 关键点附近出现「大单卖出 + 不再有主动买」→ 止盈/止损，不等反弹。
- 关键点附近出现「放量突破 + 主动买持续」→ 接力成立，可以把锚点上移画下一条线。
- 不必花钱买 Level2：作者提到用「主力主动买卖」的简化小工具即可，公开口径也能取到。

## 8. 组合拳二：KDAS + 成交量

案例：豆粕 ETF（159985），5 分钟图。

- 前期关键点：**1.973**（KDAS 黄线一带）。
- 价格盘中下探到 1.967，看似破位。
- 但成交量栏出现**放量**，且价格**重新站回 1.973**——「放量伴随的是重回 1.973，而不是跌破」。
- 结论：**假破位 / 洗盘**，随后一路上行，上方压力看 2.02。

**要点**：破位本身不构成卖出理由，**「破位 + 放量下跌 + 站不回去」才是**。
「放量 + 快速收回关键点」是强度最高的确认信号之一，比单纯看 K 线形态可靠。

另一个案例：中药 ETF（159647），高位 KDAS 跌破后，下方绿线 0.976、红线 0.969 成为支撑，「加自选设置价格预警，到了再看关键点附近的资金信息」——**不预测，只等价格到点后验证**。

## 9. 组合拳三：KDAS 分时图做 T

### 9.1 定位

> KDAS 分时图指标主要是在分时图界面划线，所以它重点关注的是**日内波动**。
> 适用范围主要是：当天临近突破右侧买点，或者突破右侧买点后遇到一根大阳线直接进入右侧空间，**日线级别的 KDAS 暂时还没跟上来**，无法指导支撑压力位时，临时做个参考。

典型场景（原文案例）：再鼎医药单日 18% 涨幅，日线 KDAS 还没跟上，就用分时指标——**在蓝线基础上做接力模式，不破就不用管**。

### 9.2 两个分时版本的区别

| | KDAS 分时 | KDAS 自动分时 3 |
|---|---|---|
| 锚点 | 手动填 3 组「日 + 时 + 分」 | 自动：最近 N 日内最高价 / 最低价所在时点 |
| 参数 | 15 个（Y/M/D/H/F × 3） | N、N2（默认 2，即近 2 日高低点） |
| 适合 | 已知某个关键时点（开盘 9:31、某次拉升高点 10:57、某次跳水 13:15） | 不知道关键点在哪，让指标自己找最近的日内高低点 |
| 逻辑 | 从锚点分钟起算的 VWAP | 从「近 N 日新高/新低」那根 K 线起算的 VWAP |
| 数量 | 橙 / 青 / 洋红 三条 | 动态均价线（橙）、动态均价线 L（青）两条 |

**自动分时的判定条件**（源码）：
- 高点线：`动态均价线` 仅在「最近一次 N 日新高比上一次更新」且「现价低于该高点」时画出——即价格从高点回落，才用高点到现在的均价做压力。
- 低点线：`动态均价线L` 同理，价格从低点反弹后，用低点到现在的均价做支撑。
- 图上 `DRAWICON` 在创新高/新低处打点，便于定位锚点。

### 9.3 分时案例：百润股份（002568），2025-06-13

- 开盘 28.03 附近，橙线压在头上，价格一路下行。
- 下方青线、洋红线逐级形成支撑（两个黄箭头），价格在 26.5–26.8 反复。
- 读法：**橙线不破不追多，青线不破不做空**；跌破支撑接力下移，站上压力接力上移。

### 9.4 做 T 的规则

- 做 T 的基准就是**震荡区间的上下沿**（压力位卖、支撑位买），不是凭感觉。
- 「震荡区间一定要积累些做 T 的利润」——这笔利润的用途是**对冲后面破位时的心理成本**，让你砍得下手。
- 日内强弱分界线（如 0.733、0.595）不破可以继续持有，破了先减。
- 震荡市里，**ETF 强弱指标**可以辅助：连续弱势后继续跌 → 可能日内反弹；连续强势后继续冲高 → 可能日内回落。

## 10. 副图指标：超跌 / 超买提示器

`KDAS副图指标2` 没有参数（内部固定），逻辑是「RSI + 30 日极值 + OBV」三重确认，只在**同时满足**时打图标：

| 组成 | 源码 | 含义 |
|---|---|---|
| RSI(9) | `SMA(MAX(C-REF(C,1),0),9,1)/SMA(ABS(C-REF(C,1)),9,1)*100` | 短期超买超卖 |
| OBV 近似 | `SUM(IF(C>REF(C,1),VOL,-VOL),0)` | 量能方向累积 |
| 30 日低点 | `LLV(LOW,30)`、`LLVBARS` | 找最近的支撑极点 |
| 30 日高点 | `HHV(HIGH,30)`、`HHVBARS` | 找最近的压力极点 |
| 触底判定 | `LOW<=30日低点 OR 差距<该K线振幅` | 价格已到支撑区 |
| 触顶判定 | `HIGH>=30日高点 OR 差距<该K线振幅` | 价格已到压力区 |

**买入图标（图标 11，在 LOW 处）** 需同时满足：
1. 昨日 RSI < 22（或今日 RSI < 22）；
2. 今日 RSI 高于「前一个低点处的 RSI」（动能背离修复）；
3. 价格触及 30 日低点区域；
4. OBV 高于 30 日最低 OBV（量能没有同步新低）。

**卖出图标（图标 9，在 HIGH 处）** 为镜像条件：RSI > 75、RSI 低于前高处的 RSI、触及 30 日高点区域、OBV 低于 30 日最高 OBV。

**用法**：这是**辅助提示器，不是交易系统**。它回答「这里是不是极值区」，不回答「该不该买」——后者仍然要回到 KDAS 状态（是不是右侧买点/震荡区间下沿）和资金面。

## 11. 资金面仪表盘：八个指标怎么读

> 每天盘前固定拉八组数据，重点不在数据本身，**在「怎么读」**。

| 指标 | 读法 | 关键阈值/信号 |
|---|---|---|
| **散户活跃度** | 与中证全指叠加对比，核心择时指标 | <40% 躺平；40–55% 正常轮动；**46–48% ≈ 历史回调前水位**；57–62% 亢奋区，「燃料」将尽 |
| **空方力量指数** | 创新高但未超前高 → A 杀概率低；接近/超过前高 → 减仓 | 接近前高 = 风险 |
| **融资盘行业净买卖** | 找资金主攻方向，必须与 ETF 申赎对照 | 融资加仓第一、ETF 仍净流出 = 分歧，反弹多高抛 |
| **指数 ETF 申赎** | 判断进出货 | **巨额单日净赎回 = 明确降温信号**；金额不大 = 偏谨慎但非出货 |
| **量能指标** | 数值维持不变 = 指数仍在震荡区间，配合上下沿使用 | **冲上 15–18 区间留意过热** |
| **ETF 强弱指标** | 连续弱势后继续跌 → 日内可能反弹；连续强势后继续冲高 → 日内可能回落 | 震荡市做 T 的参考 |
| **南下资金** | 港股节奏反向：「南进我退、南退我进」 | 南下资金接盘 = 弱 |
| **减持力度** | 审批压在窄区间 = 监管护盘；随行情大涨而放开 = 警惕 | 政策温度计 |

**最该先复刻的三个**（公开口径都能取到）：
1. **散户活跃度** → 择时
2. **融资盘行业净买卖** → 找方向
3. **ETF 申赎** → 判进出

**比数值更重要的是背离**：
> 活跃度反弹速度比指数快，就要警惕短期是否是散户资金主导上涨？这时容易收网。

注意适用边界：散户资金、南下资金的规律在**存量资金震荡市**里最明显；极端高位/极端低位时规律会变形。

## 12. 散户反向策略：怎么找潜伏标的

**总原则**：存量资金博弈的震荡市里，**和散户反着来**。

散户追着买、加速买、指数却滞涨的行业 → 退出；
散户一直卖、加速卖、指数反而企稳的行业 → 潜伏。

### 12.1 三种组合，只有两种能做

| 组合 | 判断 | 动作 |
|---|---|---|
| 散户**加速买** + 指数**滞涨** | 散进我退 | 退出 / 减仓 |
| 散户**加速卖** + 指数**企稳** | 散退我进（筹码集中，拉升阻力小） | 潜伏 |
| 散户**停止割肉转买** + 指数**未企稳** | 无法判断 | 战略性放弃 |

### 12.2 精髓在「背离」

> 芯片和 5G 通信同样遭遇散户卖出，但芯片指数没企稳——资金决心不明，放弃；5G 通信指数已经企稳——说明有实力更强的资金在散户割肉时接筹码，大概率反弹。

**同样是「散户在卖」，指数企稳的那个才值得潜伏。** 单看资金流向不够，必须两个条件同时看：**散户进出方向 + 指数是否背离**。

### 12.3 策略边界

> 散户超级亢奋期，「散进我退」会失效——你无法估计这些火箭燃料多久烧完。

此时改用 **KDAS 接力模式不断找支撑位，破位再退**，而不是一看到散户进场就跑。

> 「就像对面刚冒出几个侦察兵，你就全军后撤，那后面仗还怎么打。」

## 13. 仓位：状态决定仓位 + 三道减仓闸

### 13.1 六档仓位（满仓 = 10 成）

| 状态 | 仓位 | 备注 |
|---|---|---|
| 自然寻底 | **0–1 成** | 不接飞刀，等站上最后一根 KDAS |
| 右侧买点 | **2–3 成** | 突破即入；错了次日破位就走 |
| 震荡区间 | **3–5 成底仓** | T 的利润对冲破位时的心理成本 |
| 右侧空间 | **5–7 成** | 真空区内做向上接力 |
| 右侧趋势 | **持有不加** | 只盯移动支撑，破位即减 |
| 右侧追涨 | **0 成** | 离买点已远，不参与 |

**原则：状态决定仓位，不靠感觉。**

### 13.2 三道减仓闸（任一触发都动手）

**① 技术闸**
- 跌破接力模式下最近一条 KDAS 支撑位。
- 原话：「刚跌破的时候是控制仓位最好的时候，**错过最优解，未必会有次优解**。」
- 弱转强买入后，再次强转弱时**平推出局**，尽量减少本金折损。

**② 情绪闸**
- 盘前笔记的量能指标冲上 15–18 区间 → 留意过热。
- 盘中散户活跃度逼近 46–48% 历史回调前水位，或活跃度反弹快于指数 → 边打边撤。

**③ 资金闸**
- 宽基 ETF 连续大额净赎回 → **只在区间下沿低吸，不在上沿追**。

### 13.3 全局纪律

- 极端行情不出手，有的时候就是要蹲机会；**宁可不做，不可做错。**
- 承认这是概率游戏：**十次对八次就能积累不少利润，但十次对八次的前提，是你起码得做十次。**
- 所以必须分仓——单吊一只股，一年都未必能做十次。

## 14. 一个交易日怎么串起来

| 时段 | 栏目 | 内容 | 回答的问题 |
|---|---|---|---|
| **盘前 08:25** | 《股市数据分析》 | 拉市场体温计：散户活跃度、融资盘行业净买卖、ETF 申赎、量能、ETF 强弱榜、南下资金、宏观数据 | 今天什么天气？亢奋还是躺平？资金主攻哪个方向？有没有背离？ |
| **盘中 11:50** | 《盘中 ETF 分析》 | 把所有跟踪板块按 KDAS 状态分类（右侧趋势/震荡区间/自然寻底），逐个给强弱分界线、支撑位、压力位 | 每只 ETF 站在哪？离买卖点还有多远？哪个板块到位了？ |
| **盘后 17:00** | 盘后随笔 / 周展望 | 复盘当日结构、讲逻辑、提示风险，直接给出次日/下周操作计划 | 明天干什么？加仓还是减仓？什么条件触发动作？ |

> 盘前给数据，盘中给点位，只有盘后给的是「决策」——明天做什么、仓位往哪调、什么条件触发减仓。这种明确的「行军令」，只在盘后出现。

**提醒**：这套体系是日频更新、跟着盘面走的，本质是「订阅式服务」，不是能一次性下载离线跑的策略。**看懂方法论比抄一版点位重要得多**——点位会过期，状态判定不会。

## 15. 实操检查清单

### 盘前（10 分钟）

- [ ] 看散户活跃度：多少？和指数比，是同步还是背离？
- [ ] 看融资盘行业净买卖 + ETF 申赎：方向一致还是分歧？
- [ ] 看宽基 ETF 是否出现巨额净赎回？
- [ ] 把手里的标的逐个贴状态标签（六选一），写下今日的支撑位、压力位、强弱分界线。
- [ ] 给关键价位设价格预警（不盯盘也能等到点）。

### 盘中（价格到点时）

- [ ] 到压力位：有没有放量？有没有大单主动卖出？突破有没有秒过？
- [ ] 到支撑位：有没有放量收回？是不是「假破位」？
- [ ] 状态有没有迁移？（突破/跌破强弱分界线）
- [ ] 触发减仓闸了吗？——技术闸 / 情绪闸 / 资金闸。
- [ ] 想做 T：日内强弱分界线在哪？不破就拿着，破了先减。

### 盘后（15 分钟）

- [ ] 今天的操作是否符合「状态 → 动作 → 仓位」的对应关系？
- [ ] 明天什么条件加仓、什么条件减仓？（写成 if-then，不写「看情况」）
- [ ] 有没有在非关键点被资金数据带节奏？

## 16. 常见错误与边界条件

| 错误 | 纠正 |
|---|---|
| 把 KDAS 当均线，找金叉死叉 | 它是「成本线 + 状态机」，核心是突破/跌破后的**状态迁移**，不是均线交叉 |
| 以为颜色代表强弱 | 颜色只对应锚点序号；强度由**距离现价的远近 + 首次/反复接触**决定 |
| 把「右侧空间」当「右侧买点」 | 右侧空间是持有/加仓区，不是随手买入区；小空间里两三大阳线就到压力位 |
| 在压力位附近追涨 | 那是卖点不是买点（尤其存量资金市） |
| 任何时间都看资金流 | 只有关键点附近的资金数据有解释力，其余是伪装 |
| 「没看到大单卖出」= 没出货 | 大单跑完后会用小单/伪装散户单出货，图上不显示 |
| 破位后等反弹确认再减 | 「错过最优解，未必会有次优解」 |
| 散户一进场就全撤 | 亢奋期该策略失效，改用 KDAS 接力，破位再退 |
| 单吊一只、重仓一把 | 概率游戏需要样本量，必须分仓 |
| 以为指标可以离线跑 | 日频体系，状态每天在变，点位会过期 |

**指标本身的边界**
- 个股版不适用指数（成交额/成交量口径不同）。
- 分时版只解决「日线还没跟上」的临时问题，不替代日线状态判定。
- 源码有 2026-04-30 的版本校验，过期只显示水印。
- 副图指标是极值提示器，不是买卖系统。

## 17. 术语表

| 术语 | 含义 |
|---|---|
| **KDAS** | Key point Data Analysis System，关键点的数据分析体系 |
| **关键点** | 由 KDAS 线切出来的价格坐标，是多空行为最容易暴露的位置 |
| **锚点** | 计算某条成本线的起始时点（日期 / 日+时+分） |
| **成本线** | 从锚点到当前的成交量加权平均价（VWAP） |
| **接力模式** | 突破/跌破一条线后，把锚点上移/下移，引出下一条线 |
| **拆线** | 5 组参数用完后，把早期无意义的锚点改到最新关键日，继续接力 |
| **强弱分界线** | 接力出来的最后一两条线，唯一的状态开关 |
| **自然寻底** | 一路向下、站不上强弱分界线的过程，只能向下接力 |
| **右侧买点** | 从底部突破强弱分界线的那一刻 |
| **右侧空间** | 突破后、中远期压力位之前的真空段 |
| **右侧趋势** | 上方已无明显压力位的趋势段 |
| **右侧追涨** | 涨了一大截才介入，盈亏比差，不参与 |
| **主动买卖** | 挂高价买 / 挂低价卖，主动成交；反之是被动（挂单）成交 |
| **日内强弱分界线** | 当日多空分界价，用于做 T 的止盈止损 |
| **A 杀** | 冲高后快速杀跌的走势 |

## 18. 附录：公式源码与安装

### 18.1 安装步骤（同花顺 / 通达信通用）

1. 打开「公式管理器」→「技术指标」→「新建」。
2. 粘贴源码，**画线方法选「主图叠加」**（副图指标除外）。
3. 按源码头部参数表逐个添加参数（名称、最小、最大、缺省值必须一致，否则锚点日期错位）。
4. 保存后，在 K 线图主图选择该指标；分时版需切到分时图再选主图指标。
5. 指标标题栏会显示五条线的当前数值，顺序与参数组一一对应，便于快速读数。

### 18.2 个股版核心源码（KDAS个股1）

```
X_1:=1260430;
X_2:=HHV(DATE,0);
X_3:=IF(X_2>X_1,1,0);
X_4:=(Y1-1900)*10000+M1*100+D1;
X_5:=BARSLAST(DATE-X_4=0);
X_6:=AMOUNT/(VOL*100);
X_7:=SUM(X_6*VOL,X_5)/SUM(VOL,X_5);
IF(X_3=0 AND DATE>X_4,X_7,DRAWNULL),COLOR007FFF,LINETHICK2;

X_8:=(Y2-1900)*10000+M2*100+D2;
X_9:=BARSLAST(DATE-X_8=0);
X_10:=AMOUNT/(VOL*100);
X_11:=SUM(X_10*VOL,X_9)/SUM(VOL,X_9);
IF(X_3=0 AND DATE>X_8,X_11,DRAWNULL),COLORRED,LINETHICK2;

X_12:=(Y3-1900)*10000+M3*100+D3;
X_13:=BARSLAST(DATE-X_12=0);
X_14:=AMOUNT/(VOL*100);
X_15:=SUM(X_14*VOL,X_13)/SUM(VOL,X_13);
IF(X_3=0 AND DATE>X_12,X_15,DRAWNULL),COLORYELLOW,LINETHICK2;

X_16:=(Y4-1900)*10000+M4*100+D4;
X_17:=BARSLAST(DATE-X_16=0);
X_18:=AMOUNT/(VOL*100);
X_19:=SUM(X_18*VOL,X_17)/SUM(VOL,X_17);
IF(X_3=0 AND DATE>X_16,X_19,DRAWNULL),COLORGREEN,LINETHICK2;

X_20:=(Y5-1900)*10000+M5*100+D5;
X_21:=BARSLAST(DATE-X_20=0);
X_22:=AMOUNT/(VOL*100);
X_23:=SUM(X_22*VOL,X_21)/SUM(VOL,X_21);
IF(X_3=0 AND DATE>X_20,X_23,DRAWNULL),COLORLIGRAY,LINETHICK2;
```

> 个股 2/3/4 源码与上完全相同，仅默认锚点日期不同（例如个股2 的 M2 缺省为 4、个股3 的 M2 缺省为 3）。

### 18.3 分时版核心源码（KDAS分时）

```
X_4:=YEAR=Y1 AND MONTH=M1 AND DAY=D1;
X_5:=YEAR=Y1 AND MONTH=M1 AND DAY=D1 AND HOUR=H1;
X_6:=YEAR=Y1 AND MONTH=M1 AND DAY=D1 AND HOUR=H1 AND MINUTE=F1;
X_7:=IF(PERIOD=5,X_4,IF(PERIOD=4,X_5,IF(3,X_6,DRAWNULL)));
X_8:=BARSLAST(X_7);
X_9:=(CLOSE+HIGH+LOW)/3;
KDAS:IF(X_3=0 AND X_8>=0,SUM(VOL*X_9,X_8+1)/SUM(VOL,X_8+1),DRAWNULL),COLOR007FFF,LINETHICK4;
```

三组参数分别对应橙、青（`COLORCYAN`）、洋红（`COLORLIMAGENTA`）三条线。`PERIOD` 判断的作用：日线周期只用日期匹配，小时周期用「日期+小时」，分钟周期用「日期+小时+分钟」。

### 18.4 自动分时版核心源码（KDAS自动分时3）

```
X_4:=HHV(HIGH#DAY,N);
X_5:=HIGH=X_4 AND REF(HIGH,1)<X_4;      // 创 N 日新高
X_6:=BARSLAST(X_5);
X_9:=(HIGH+LOW+CLOSE)/3;
X_10:=SUM(VOL*X_9,X_6+1);
X_11:=SUM(VOL,X_6+1);
动态均价线:IF(X_3=0 AND X_8=0 AND X_6>=0 AND DYNAINFO(7)<X_4,X_10/X_11,DRAWNULL),COLOR007FFF,LINETHICK4;
```

下半段是低点镜像（`LLV(LOW#DAY,N2)` → `动态均价线L`）。**核心是锚点自动化**：不用填日期，指标自己找到最近的高低点，从那里开始累加均价。

### 18.5 副图指标关键源码（KDAS副图指标2）

```
X_4:=9;  X_5:=30;  X_7:=22;  X_8:=75;   // RSI周期 / 极值周期 / 超卖线 / 超买线
X_10:=SMA(MAX(CLOSE-X_9,0),X_4,1)/SMA(ABS(CLOSE-X_9),X_4,1)*100;
X_12:=SUM(IF(CLOSE=REF(CLOSE,1),0,X_11),0);   // OBV
X_32:=REF(X_10,1)<X_7 OR X_10<X_7 AND X_10>X_24 AND X_21 AND X_12>X_19;
X_33:=REF(X_10,1)>X_8 OR X_10>X_8 AND X_10<X_23 AND X_22 AND X_12<X_20;
DRAWICON(X_32 AND X_3=0,LOW,11);   // 低吸提示
DRAWICON(X_33 AND X_3=0,HIGH,9);   // 高抛提示
```

## 19. 不需要付费数据源：用公开行情复现 KDAS

iFinD 只是「取数更方便」，不是必需品。KDAS 的输入只有四样东西：**开、高、低、收 + 成交量 + 成交额**，这些公开行情接口都有，且不需要密钥。

### 19.1 数据源

| 用途 | 接口 | 说明 |
|---|---|---|
| 日线（含成交额） | 东方财富 `push2his.eastmoney.com/api/qt/stock/kline/get` | 免费、无需密钥，支持前复权 `fqt=1` |
| 当日分时（1 分钟） | 东方财富 `.../stock/trends2/get` | 盘中实时可用，历史仅保留最近几个交易日 |
| 备用 | 腾讯 `qt.gtimg.cn`、新浪 `hq.sinajs.cn` | 无成交额字段时可用「均价×成交量」近似 |

### 19.2 配套工具 `tools/kdas.py`

纯 Python 标准库，无第三方依赖、无密钥，可直接跑：


### 19.3 算法对应关系（必须注意的两个细节）

1. **日线要「排除锚点日」**。源码是 `SUM(X, BARSLAST(DATE=锚点))`，`BARSLAST` 返回的是「距锚点的 K 线数」，而 `SUM(X,N)` 取最近 N 根，窗口实际是 **锚点次日 → 今天**，不含锚点当天。
   用错（把锚点日算进去）会出现 0.7175 vs 正确 0.7234 这种偏差，看着很小，但足以让你误判压力位。
2. **分时相反，要「包含锚点分钟」**。源码写的是 `SUM(VOL*典型价, X_8+1)`，多加了 1，窗口从锚点那一分钟开始。
3. 日线用 `成交额/成交量` 直算；分时用 `(H+L+C)/3` 典型价加权——与源码一致，不能混用。

### 19.5 局限与边界

- **锚点仍然要人来定**。工具只负责算，不负责「哪个日子是关键点」——这是 KDAS 的主观部分，也是它有效的原因。`--suggest` 只给候选（阶段高低点、放量日），最终由你决定。
- **状态初筛是启发式**。脚本里的「六状态」判断基于「价格与五条线的相对位置 + 距离」，只用于快速定位，**不能替代人工判断**，尤其区分不了「右侧买点」和「震荡区间」。
- **前复权口径**。成交额/成交量是原始值，K 线是前复权值；发生分红送转的个股，长周期线的绝对值会和券商软件略有差异。ETF 基本无此问题。
- **分时历史有限**。公开接口只给最近几天的 1 分钟数据，没法回溯 2025 年某天的分时；要做历史分时验证，得自己盘中落库。
- **iFinD 仍有不可替代的场景**：财务数据、宏观/行业指标、资金流向、公告舆情。取价算线用免费源，取基本面用 iFinD，两条腿走最省事。

## 20. 风险提示

- 本文档是对公开文章与指标源码的**学习整理**，不构成任何投资建议。

- 指标参数（锚点日期）带有主观性，不同锚点会得到不同结论——**先固定一套自己的锚点规则，再谈一致性执行**。
- 原文作者已声明：公开只聊行业和 ETF，不回答个股问题；个股波动大，容易震出局。
