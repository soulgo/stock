# ADR-002: 指标段先出 dict 再出文本——文本契约的分步收敛

## Status
Accepted（2026-11-18），**部分实施**：已完成 `market` / `margin` / `news` 三段；`impulse` / `ratio` 早已是 snapshot→文本两段式，无需改。

## Context

`brief.py` 与 `report_gen.py` 之间唯一的接口是**标准输出里的文本**：

- 产端：`brief.py` 用 171 处 `print` 定义格式（两空格 + 标签 + 2 个以上空格 + 值）；
- 消端：`report_gen.py` 用 21 个 `parse_*`、72 处正则，按标签反猜。

这份契约没有任何机器可校验的约束，已经造成的三类事故（`HANDOFF.md` 坑 #3 / #4 / #5）根因相同：**格式漂移不报错，只是静默少一块**。

同时还带来两处数据损伤：

1. **精度二次损失**：价格印 3 位小数，再被 `parse` 读回 float。曾导致 512170 的 T 空间显示 3.4%、实际 3.37%，定稿前要另调 `brief.levels()` 打 4 位。
2. **缺值与零同形**：`num("—")` 返回 `0.0`，`cls(0)` 返回 `flat`。渲染层为此写了 28 处判断 `"—"` 的分支来对冲。

## Decision

**分两步收敛，第一步只动产端。**

第一步（本次）：把指标段拆成 `xxx_data()` → dict → `xxx_render(d, no)` → 行列表 → `xxx_block()` 逐行 print。

- `xxx_data()` **只取数**：缺失一律 `None`，不写 `"—"`、不补 `0`；
- `xxx_render()` **只格式化**：单位换算、`"—"`、条件后缀（如「较上一记录」「区间首日无前值」）全部集中在渲染层，成为格式的唯一真源；
- `xxx_block()` 保持原签名，`BLOCKS` 注册表与调用方零改动；
- **输出文本一字不变**，所以 `report_gen.py` 一行不用改。

第二步（未做，待触发）：`report_gen` 改为直接读 dict，文本降级为「人读面板」的一个可选渲染目标。

## Consequences

**已经拿到的**

- 格式只有一个定义处：改一个标签，不再需要在 `print` 与正则之间来回对。
- 「没取到」与「等于 0」在数据层就分开了，渲染层才有资格决定显示成 `—` 还是 0。
- 数字以 float 形式穿过数据层，不再经过 3 位小数的格式化往返。
- 可以在**不碰渲染**的前提下单测数据层：给定冻结快照，断言 dict 字段。
- 为新指标预留了落点：加一段 = `data()` + `render()` + `BLOCKS` 一行。

**代价**

- 每个指标段多一层函数调用与一个 dict，读代码要跳两次（`block → render → data`）。
- dict 字段没有 schema 约束，字段名仍是口头约定（JSON Schema 属第二步）。
- 本次只覆盖 3 段，`morning()` / `noon()` / `evening()` 里的固定前段仍是直接 print —— 那里是稳定的，动它没有未来收益。

**过程中发现的既有缺陷（已顺带修）**

`market_data` 里 `ff[c]` 在「载具规模有值、载具资金流缺失」时抛 `KeyError`，旧版表现为**整段丢失**（被 `emit_blocks` 的 except 吞掉，只留段头和「取数失败」）。改为 `ff.get(c) or {}`。此差异已在对拍中单列为「已知差异」，不是回归。

## Alternatives considered

| 方案 | 放弃原因 |
|---|---|
| **一次性全换 JSON，`report_gen` 同步改** | 4 份定时任务 prompt 里写死了回执判据（「解析：4 条指数 / 7 只持仓」），而云端两份只读；契约与渲染同时改，出问题时无法区分是哪一侧的错 |
| **只拆文件不换契约**（把 `brief.py` 拆成 5 个模块） | 文件变短但耦合没变，171 处 print 与 21 个 parser 依然靠人脑对应；拆文件只在换契约时顺手做才有意义 |
| **文本契约完全保留，只加校验函数** | 校验只能事后发现，不能阻止「格式已漂移但今天恰好没触发」的隐性腐化 |

## 怎么验证（沿用，别退化成肉眼看）

`A/B 对拍`：把旧版从 git 取出，两版吃**同一份冻结输入**（`data/_mx_<date>.json` + 两融缓存 + 快讯 fixture，并把 `intraday_progress` / `pool_baseline` 钉成常量），逐字节比较三个段在 morning/noon/evening 下的 stdout。

- 正常路径 7 例、退化输入 6 例（空快照、无概览、无资金流、无 quotes、基准全 0、两融无记录）全部一致；
- 唯一差异是上述 `KeyError` 修复。
