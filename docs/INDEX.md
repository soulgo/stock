# docs/ 索引

本目录只放**只读资料**：理论、外部研究、架构决策。日常操作文档仍在根目录（`readme.md` / `HANDOFF.md` / `strategy_rules.md` / `changelog.md`），因为它们每天都要打开，且被定时任务 prompt 按文件名引用。

| 文件 | 是什么 | 什么时候读 | 维护方式 |
|---|---|---|---|
| `KDAS手册.md` | KDAS 关键点体系手册（771 行）：微观结构、分时、资金验证、五色线 | 需要理解「支撑/压力怎么画出来」「六状态凭什么这么判」时 | 体系认知更新时改；**不参与自动决策** |
| `research/策略体系梳理_Tony.md` | 外部资料（3 份 PDF）的通读整理，含原文页码索引 | 追溯 `strategy_rules.md` 里某条规则的出处时 | 一次性存档，**不再更新** |
| `adr/ADR-001-目录分层.md` | 目录为什么这么分层、放弃了哪些方案 | 想再动目录结构之前 | 新的结构调整另起 ADR，不改旧文 |
| `INDEX.md` | 本文件 | 找不到东西时 | 增删文件时同步 |

## 命名与归属规则（新文件往哪放）

| 你新增的东西 | 放哪 | 判据 |
|---|---|---|
| 每天被定时任务调用的入口 | 根目录 | 会被 automation prompt 写进命令 |
| 某个指标的计算 + 文本段 | `indicators/` | 对应一条 `knowledge/K0x.md` |
| 偶尔手动跑的脚本 | `tools/` | 不在日链上，失败不影响当天报告 |
| 脚本产出、不需要人读 | `data/` | 可随时删除重建 |
| 人要看、要留档 | `reports/` | 按 `<类型>_<YYYY-MM-DD>` 命名 |
| 理论 / 外部资料 / 决策记录 | `docs/` | 只读为主 |

**一条硬规则**：任何新脚本的路径都不要自己拼字符串，从 `paths.py` 取（`ROOT` / `DATA` / `REPORTS` / `ARCHIVE`，或 `data()` / `report()` 两个辅助函数）。
